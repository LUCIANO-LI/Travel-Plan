# Travel-Plan

个人旅行攻略合集，记录每次出行的行程规划、美食推荐和实用信息。

所有攻略均为可直接浏览的 HTML 页面，开启 GitHub Pages 后可在手机上随时查看。

## 攻略列表

| 目的地 | 天数 | 在线查看 |
|--------|------|----------|
| 台湾（台北→台中→台南→高雄） | 6天5晚 | [查看攻略](Taiwan/taiwanplan.html) |
| 伦敦（泰晤士河→街区漫步→西区→格林威治） | 3天2夜 | [查看攻略](London/londonplan.html) |

## 使用方式

- **手机/电脑浏览**：访问 https://luciano-li.github.io/Travel-Plan/
- **导出 PDF**：打开攻略页面，点击页面顶部「导出 PDF」按钮
- **离线使用**：直接下载 HTML 文件，浏览器本地打开即可
